## Objective
Add a `--limit <n>` flag to `baton task list` that caps the number of tasks printed.
When `--limit 5` is passed, only the first 5 tasks (by ID order) are printed.
Without the flag, all tasks are printed (current behavior).

## Definition of done
- `baton task list --limit 3` prints at most 3 tasks
- `baton task list` (no flag) prints all tasks (unchanged)
- `npx tsc --noEmit` passes
- Existing tests pass
