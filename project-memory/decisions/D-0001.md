## Decision
Every new command lives in its own file under src/commands/, imported and registered in src/cli.ts. Commands never import each other. Shared logic lives in core/. The CLI file is commander wiring only.

## Why
The existing codebase follows this pattern. Breaking it causes circular dependencies and makes commands hard to test in isolation.

## Alternatives
- Put all commands in cli.ts — file exceeds 300 lines (G43 violation)
- Commands import each other — creates coupling, hard to test
